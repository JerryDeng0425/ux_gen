# Step 09：可靠性与性能验收

## 目标

用重复运行和边界测试量化证明工具满足 PRD 第 11.2 节，而不只完成一次演示。

## 前置条件

- Step 08 的验证器可以自动判断每次运行结果。
- 测试机器、浏览器版本、视口和网络条件已记录。

## 实施任务

1. 本地一致性站点执行全量功能回归和异常注入。
2. Vuestic K01–K04 各完成 20 次有效采集。
3. 统计快捷键延迟、DOM 序列化和全部产物保存的 p50/p95。
4. 验证 50,000、150,000 节点和 25 MB 边界。
5. 验证导航中、页面关闭、重复触发和磁盘写入失败后的恢复。
6. 执行隐私、安全、文件覆盖和关键点串台统计。
7. 生成逐项对应 PRD 指标的 `acceptance-report.json` 和摘要。

## 交付物

- 性能原始数据。
- 20 次重复运行结果。
- 异常注入报告。
- 机器可读验收报告和结论摘要。

## 可验收项

| ID | 验证方法 | 通过标准 | 验收证据 |
| --- | --- | --- | --- |
| AC-09-01 | K01–K04 各执行 20 次 | 每个关键点 20/20 功能通过 | 80 次结果汇总 |
| AC-09-02 | 统计快捷键到同步克隆开始 | p95 不高于 200 ms | 原始时间样本和统计 |
| AC-09-03 | 对不超过 50,000 节点的 DOM 采样 | 序列化 p95 不高于 1 s | 性能报告 |
| AC-09-04 | 统计单关键点全部产物保存 | p95 不高于 3 s | 性能报告 |
| AC-09-05 | 比较指定文本、属性和表单状态 | 一致率 100% | Validator 汇总 |
| AC-09-06 | 汇总 HTML 解析和截断 | 解析成功率 100%，截断数 0 | 完整性报告 |
| AC-09-07 | 汇总安全与隐私扫描 | 可执行站点脚本、password/file 泄漏均为 0 | 扫描汇总 |
| AC-09-08 | 检查命名和关键点关联 | 文件覆盖和关键点串台均为 0 | 一致性报告 |
| AC-09-09 | 联网视觉回放 | 动态区 mask 后差异像素不高于 5% | 视觉差异报告 |
| AC-09-10 | 超过 150,000 节点或 25 MB | 按契约标记 oversized，不崩溃、不写半文件 | 边界测试日志 |
| AC-09-11 | 检查 acceptance report | 每项包含环境、样本数、结果、阈值和证据路径 | `acceptance-report.json` |

## 暂停条件

如果 50,000 节点序列化无法达到 1 秒 p95，暂停公开网站重复验收，先对遍历、canvas 和字符串生成做性能剖析。不得通过延迟克隆来放宽关键时点语义。

## 完成判定

AC-09-01 至 AC-09-11 全部 `PASS`；任何未达标项都必须有可复现用例、原因和修复后复测结果。
