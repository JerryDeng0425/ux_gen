# Step 11：端到端验收与交付

## 目标

从干净环境分别验证直接工具模式和 Skill 模式，证明两者共享同一能力、产物契约和验收结果。

## 前置条件

- Step 00–10 的 P0 验收项全部通过。
- 已冻结待发布版本、场景版本、Chromium 版本和依赖锁文件。

## 实施任务

1. 在干净环境执行依赖安装、浏览器安装和预检。
2. 直接用 CLI 完成一次 Vuestic K01–K04。
3. 由 Codex Skill 引导完成另一次 K01–K04。
4. 对两次运行分别执行历史产物验证。
5. 比较 schema、状态机、warnings、断言和安全结果。
6. 对照 PRD MVP 完成定义建立需求—测试—证据追踪矩阵。
7. 整理 canvas/WebGL、Shadow DOM、跨域 iframe 和在线资源依赖等已知限制。
8. 归档版本信息、验收报告、样例产物和使用入口。

## 交付物

- CLI 模式和 Skill 模式的完整运行目录。
- 两份 validation report 和最终 acceptance report。
- PRD 追踪矩阵。
- 已知限制与后续 backlog。

## 完成判定

PRD MVP 完成定义全部签收，工具模式与 Skill 模式没有功能分叉，所有报告和证据均可从追踪矩阵定位。
